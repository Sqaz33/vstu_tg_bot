# VSTU Schedule Bot

Telegram-бот расписания ВолгГТУ. Источник данных — официальные Excel-файлы,
которые университет публикует на странице расписаний. Текущая конфигурация
выбирает один файл магистратуры: **1 курс ФЭВТ.xls**.

Проект находится в разработке. Полная инструкция запуска будет добавлена вместе
с рабочим приложением.
